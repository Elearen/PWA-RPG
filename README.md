# PWA RPG

A persistent, story-driven RPG designed as a mobile-first progressive web application.

The project combines a deep RPG progression and equipment system with automated/state-based combat, exploration, journeys, dungeons, quests, NPCs, factions and a persistent evolving world.

The narrative is built around **three distinct protagonists and starting locations**, allowing the player to experience the same wider world and unfolding events from different perspectives. Story is delivered primarily through exploration, encounters, quests and short Journal-based story bites rather than long conventional dialogue sequences.

The game world is a grounded fantasy setting containing diverse regions, societies, political tensions, dangerous wilderness and deeper mysteries connected to its distant past. Exploration gradually expands the player's understanding of both the immediate world and the larger story behind it.

The project is designed as a **single-player experience with persistent progression**, supported by an optional no-stakes duel simulator that allows players to compare their character builds without affecting their actual game state.

The technical architecture is designed for **Bolt-based development and hosting**, with persistent backend storage and server-authoritative game logic. The system is intentionally modular so that individual game systems can evolve independently and additional content can be introduced over time.

* skills and abilities

The specifications are the authoritative design documents for implementation.
